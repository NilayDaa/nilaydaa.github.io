ABOUT ME

Security, automated.

I'm a cybersecurity and AI student at JAMK University of Applied Sciences, living in Helsinki. My focus is the point where the two fields collide: using machine learning and automation to make security operations faster, and using an attacker's mindset to keep AI applications honest.

Before university I worked in operations as a computer operator — long shifts watching systems behave, and building the instinct for "that's not normal" that SOC work demands. Today that instinct has a toolchain: Wazuh and Suricata for detection, Python and FastAPI for automation, Docker and Azure for deployment, and a growing collection of LLM security notes.

Everything here is built in public — labs, automations, mistakes and all. The learning roadmap I run is generated and tracked by a GitHub Actions scheduler, so the machine keeps me honest about showing up every day.
